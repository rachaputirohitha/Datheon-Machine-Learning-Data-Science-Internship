# Datheon Machine Learning and Data Science Internship

This repository contains three machine learning projects completed as part of the Datheon Machine Learning and Data Science Internship.

## Projects

### Task 1: Iris Flower Classification
**Objective:** Classify Iris flowers into their respective species using the Iris dataset.

**Models used:**
- Logistic Regression
- Decision Tree Classifier

**Work completed:**
- Data exploration and visualization
- Duplicate handling and feature scaling
- Training and testing data split
- Model evaluation using accuracy, precision, recall, F1-score, and confusion matrices
- Feature importance visualization

### Task 2: House Price Prediction
**Objective:** Predict California house values using housing features.

**Models used:**
- Linear Regression (OLS)
- Ridge Regression
- Lasso Regression

**Work completed:**
- Missing-value handling
- Categorical feature encoding
- Training and testing data split
- Feature standardization
- Model evaluation using MAE, RMSE, and R²
- Actual-versus-predicted and residual plots

### Task 3: Customer Churn Classification
**Objective:** Predict whether a telecom customer is likely to churn.

**Models used:**
- Random Forest Classifier
- XGBoost Classifier

**Work completed:**
- Data cleaning and preprocessing
- Categorical feature encoding
- Class imbalance handling using class weights
- Model evaluation using accuracy, precision, recall, F1-score, and ROC-AUC
- Confusion matrices, ROC curves, and feature importance visualization
